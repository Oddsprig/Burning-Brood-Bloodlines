Prepared 2026-10-10.

WHAT THIS IS
A separate development path from Copper Oath v0.046. The player controls a
family ruling one city. Managing dragons, their riders and conventional troops
is central. Family politics, city politics, diplomacy and marriage alliances
drive the campaign. Keep Copper Oath's real economy, campaign-map style and
detailed tactical combat. Use dark green/purple presentation suited to mobile.

This package is a source handoff and design plan. It is not a playable
dragonlord build. No dragon mechanics, ruler controls or new theme have been
implemented here. Copper Oath's source and installed release remain unchanged.

Extract BASE_SOURCE_v0.046.zip into a new Burning_Brood development folder,
separate from Copper Oath. Open game/project.godot in Godot 4.7.2.
Create a separate repository/development branch, suggested dev/burning-brood.
Use the included source snapshot as the baseline; do not start from GitHub
master, v0.020 or a historical checkpoint.
Before any player-facing launch, give the new copy its own project name,
version, user-data directory, launcher and icon. Do not copy Copper Oath saves.
The source archive includes no engine binary; use Godot 4.7.2.
Keep the existing Copper Oath project, releases and launcher intact.

Work on the proposed v0.001 foundation: separate game identity, an actual
registered ruling family/person for the selected starting city, clear public
and private accounts, and the green/purple/dark UI shell. Keep the economy,
campaign map and troop battle simulation. Prove that the selected ruler is the
same person represented in the register. Treat later milestones as roadmap
work, and keep checks short, hidden and limited to detecting breakage.
